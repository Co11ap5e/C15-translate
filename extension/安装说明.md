# 本地翻译扩展

Chrome / Edge 用的 Manifest V3 扩展，把整页日文翻成中文，模型跑在本机，
内容不出本机。

## 安装

1. 双击这个目录里的 `安装扩展.bat`，它会打开浏览器的扩展管理页。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选中 `D:\DSH\local-translate\extension`。
4. 装好后工具栏上会出现图标。

## 装之前确认

本地翻译服务在跑（`D:\DSH\local-translate\启动.bat`）。打开任意网页，右下角面板上的
圆点是绿色，就说明扩展已经连上服务了。

## 怎么用

- 点工具栏图标翻译整页，再点一次还原
- 页面右下角有面板，可以选语言、模型和翻译风格，也能切换双语对照和仅译文
- 右键菜单里有翻译本页、双语/仅译文切换、隐藏译文、清除译文、翻译选中文本
- 选中一段文字，就地弹出译文气泡
- `Alt+T` 翻译本页，`Alt+Enter` 翻译输入框里的内容

输入框翻译对 React 和 Vue 的受控输入框也有效，改值的时候走的是原生 setter 再派发
input 事件，不会被框架覆盖回去。

## 和油猴版的区别

扩展版是把油猴脚本重写了一遍，功能少一些：

- 快捷键固定三个，不能自定义
- 主题和面板尺寸跟随系统，没有手动开关
- 没有导出 Anki 的按钮，也没有只翻日文的开关

换来的是不依赖 Tampermonkey，而且网络请求走后台的 service worker。
这一点是必须的：内容脚本在 HTTPS 页面里请求 `http://127.0.0.1` 会被浏览器的
混合内容策略拦掉，放到后台脚本里发请求就绕过了这个限制，代价是拿不到流式输出。

两个版本可以同时安装，但不要在同一页面同时开，会插入两遍译文。

## 改完之后

改了 `content.js` 之后，在扩展管理页点这个扩展的刷新按钮，然后刷新网页。

## 出问题的时候

- 面板上的点是红的：翻译服务没起来，去跑 `启动.bat`
- 页面完全没反应：多半是这个页面不允许内容脚本，`chrome://` 开头的页面和扩展商店
  页面都是这样，属于正常现象
- 译文出现两遍：同一页面同时开了油猴版，关掉其中一个
