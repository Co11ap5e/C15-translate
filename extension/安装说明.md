# 本地翻译扩展（Chrome / Edge，Manifest V3）

## 安装（30 秒）
1. 双击本目录里的 **安装扩展.bat**（会自动打开扩展管理页）
2. 右上角打开「**开发者模式**」
3. 点「**加载已解压的扩展程序**」→ 选择本目录 `D:\DSH\local-translate\extension`
4. 装好后工具栏出现图标 ✓

## 前置条件
本地翻译服务必须在跑（`D:\DSH\local-translate\启动.bat`）
→ 面板上的状态点如果是**绿色**说明已连上 ✓

## 用法
| 操作 | 效果 |
|---|---|
| 点工具栏图标 | 翻译本页 / 再次点击还原 |
| 页面右下角面板 | 语言对 · 模型 · 风格模板 · 翻译本页 |
| 右键菜单 | 翻译本页 / 双语·仅译文 / 隐藏译文 / 清除译文 / 翻译选中文本 |
| 选中文字 | 就地弹出译文气泡 |
| `Alt+T` | 翻译本页 |
| `Alt+Enter` | 翻译输入框里的内容（兼容 React/Vue） |
| 面板「鼠标悬停」 | 开启后鼠标停 0.35 秒就地出译文 |

## 与油猴版的区别
| | 扩展版 | 油猴版（v2.4） |
|---|---|---|
| 安装 | 开发者模式加载 ✓ | 需装 Tampermonkey |
| 网络请求 | 走 background（无混合内容限制 ✓） | 需 `@connect` 授权 |
| 快捷键自定义 | ✗（固定 3 个） | ✓（4 个可改） |
| 面板尺寸/主题手动切换 | ✗（自动跟随系统） | ✓ |
| 输入框 / 悬停 / 划词 | ✓ | ✓ |

两个版本可以共存，但**同一页面别同时开**（会重复插译文）。

## 更新
改了 `content.js` 后 → 扩展管理页点该扩展的「🔄 刷新」按钮 → 再刷新网页 ✓

## 出问题排查
- 状态点红 → 翻译服务没起（运行 `启动.bat`）
- 页面无反应 → 该页禁止内容脚本（如 `chrome://`、Chrome 商店页）✓ 正常
- 译文重复 → 同一页同时开了油猴版 ✗ 关掉一个
