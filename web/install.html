🌐 安装「本地双语翻译」用户脚本

整页扫描 + 段落级中日双语对照（沉浸式翻译风格）· 用你本机的 Ollama 模型

方式 ① 从 URL 安装（推荐，最省事）

  1. 浏览器已装好 Tampermonkey 扩展（没装先去扩展商店装）
  2. 点开 Tampermonkey 图标 → 管理面板（Dashboard） → 左侧 实用工具 / Utilities
  3. 页面底部找到 「从 URL 安装 / Install from URL」，把下面这条粘进去 → 点安装
http://127.0.0.1:18765/userscript.user.js

方式 ② 复制代码 → 粘进编辑器（100% 可用 ✓）

  1. Tampermonkey → 管理面板 → 右上角 「+」添加新脚本
  2. 点下面的「复制脚本代码」→ 回到编辑器，全选删掉模板 → 粘贴 → Ctrl+S 保存

方式 ③ 从服务器的 HTTPS 地址安装（出门在外/别的电脑用）

https://live.co11ap5e.site/sub/4d86abdd0a1150eac2daa321/userscript.user.js
（同样的方式①流程，把这条填进「从 URL 安装」即可 ✓）

装好后怎么用

  1. 确认本机跑着：Ollama + server.py（双击 启动.bat）
  2. 打开任意网页 → 右下角出现「🌐 本地翻译」面板
  3. Alt+T 翻译本页 · Alt+O 显示/隐藏译文 · Alt+A 自动翻译开关 · 划词出小气泡译文
  4. 先拿测试页试：D:\DSH\local-translate\test-page.html
